# 画像処理 受け渡し仕様（第3版：同じラズパイの中で関数を呼ぶ形）

本体と画像処理の約束は **このファイルに書いてあることだけ** です。
画像処理は本体のファイルを import しません。本体も画像処理の中身（変数・クラス・他の関数）には触りません。
共有するファイルはありません。

---

## 1. 画像処理が用意するもの

**Python のファイル 1 つに、関数 1 つ** だけです。

```python
def measure(want_shoulder, known):
    ...
    return {...}
```

- ファイルの場所は本体の `config.py` の `VISION_FILE` で指定する（既定は `vision/vision.py`）
- 本体はこのファイルを読み込み、`measure` だけを呼ぶ
- カメラやモデルの準備は、**初めて呼ばれたときに画像処理側が自分で行う**。後片付けも画像処理側で行う（`atexit` など）。準備用・後片付け用の関数は約束しない

---

## 2. 引数（本体 → 画像処理）

```python
measure(want_shoulder=True, known={"田中": <顔>, "佐藤": <顔>})
```

| 引数 | 型 | 意味 |
|---|---|---|
| `want_shoulder` | bool | True なら肩幅も測る |
| `known` | dict | 登録済みの人。キーは本体が決める名前、値は以前に画像処理が返した `face` そのもの（空のこともある） |

呼び出しの意味は「今カメラの前にいる人を1回測り、`known` の中に同じ人がいれば教えて」です。
`known` は本体が写しを渡すので、画像処理が書き換えても本体には影響しません。

---

## 3. 戻り値（画像処理 → 本体）

### 成功

```python
{"ok": True, "face": <顔>, "shoulder_cm": 45.6, "match": "田中"}
```

| キー | 必須 | 型 | 意味 |
|---|---|---|---|
| `ok` | ○ | True | 成功 |
| `face` | ○ | JSON で保存できるもの | 今測った人の顔。**本体は中身を見ずにそのまま保存し、次から `known` に入れて渡す** |
| `shoulder_cm` | want_shoulder が True のとき | 数 | 肩幅（cm）。換算・補正は画像処理側で済ませる |
| `match` | ○ | str / None | `known` の中で同じ人と判定したキー。いなければ None |
| `score` | 任意 | 数 | 似ている度合い（画面に表示するだけ） |
| `note` | 任意 | str | 利用者に見せたい一言（本体はそのまま表示する） |

### 失敗

```python
{"ok": False, "message": "顔が十分に映っていません（5 / 15 フレーム）"}
```

`message` は利用者に見せる文です。本体はそのまま表示します。
**例外を投げてもかまいません。** 本体は例外を受け止め、その内容を失敗として表示します（プログラムは止まりません）。

失敗の種類を表すコードは決めません。本体は失敗の理由で処理を変えないためです。

---

## 4. 守るルール（5つ）

1. **顔の中身は画像処理だけが知る。** 形・長さ・比べ方・しきい値・モデル名は画像処理の自由。本体は `face` を開けない。
2. **同じ人かどうかは画像処理が決める。** `match` には `known` にあるキーか None だけを入れる。
3. **戻り値は Python の基本の型だけ**（dict / list / str / int / float / bool / None）。numpy の配列や数は `.tolist()` や `float()` で直してから返す。本体が JSON で保存するため。
4. **読めない `face` が `known` に来ても止まらない。** 古い方式や別モデルの顔は照合から外し、必要なら `note` で知らせる。
5. **知らないキーは無視する。** 戻り値にキーが増えても本体は無視する。将来、引数が増えるときは省略できる形で足す。

あわせて、1回の `measure` は **20秒以内** に返してください（本体はその間、入力を待たせます）。
画像処理は `print` で自由にログを出してかまいません。
