# ラズパイ ⇔ ESP32 の命令

ラズパイ（`body/machine.py`）と ESP32（`esp32/hanger_esp32/bt_command.cpp`）の間の決まりです。
**変えるときは両方を直す必要があるので、チーム全員で決めてから変えてください。**

---

## 命令と返事

1 行に 1 つの短い命令です（ASCII、最後に改行）。

| ラズパイ → ESP32 | 意味 | ESP32 → ラズパイ |
|---|---|---|
| `PING` | つながっているかの確認 | `PONG` |
| `GET:3` | 3 番のハンガーを取り出す | `OK:GET:3` |
| `PUT:3:42.5` | 3 番を肩幅 42.5cm の人に割り当てた | `OK:PUT:3:42.5` |
| `GET:25` | 番号が範囲外 | `ERR:RANGE:GET:25` |

エラーの返事は `ERR:<理由>:<命令>` の形です。

| 理由 | 意味 |
|---|---|
| `RANGE` | ハンガー番号が 1〜`HANGER_COUNT` の外 |
| `BAD` | `:` がなく、形が読めない |
| `UNKNOWN` | 知らない種類の命令 |
| `TOO_LONG` | 1 行が 32 文字を超えた（この場合だけ命令は付かない） |

## 決まりごと

- ESP32 は、命令を受け付けたらすぐ `OK` を返し、それから動きます（動くのに時間がかかってもラズパイを待たせない）
- ラズパイは `OK` / `ERR` / `PONG` 以外の行を読み捨てます。ESP32 がデバッグ表示を混ぜても大丈夫です
- 切れたら、ラズパイが自動でつなぎ直します。まだ送れていない命令は、つながってから送ります
- 送ったのに `OK` が来ない命令は送り直しません（届いていた場合、2 回動いてしまうため）。警告だけ出します
- `HANGER_COUNT` は `body/config.py` と `esp32/hanger_esp32/bt_command.h` で同じ値にします（今は 20）
